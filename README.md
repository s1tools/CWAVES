CWAVES

** Presentation
Code implementing the CWAVE feature extraction from
Schulz‐Stellenfleth, J., König, T., & Lehner, S. (2007). An empirical approach for the retrieval of integral ocean wave parameters from synthetic aperture radar data. Journal of Geophysical Research: Oceans, 112(C3).
https://agupubs.onlinelibrary.wiley.com/doi/full/10.1029/2006JC003970

This implementation is jointly performed by CLS (A.Benchaabane) and IFREMER (A.Grouazel) as part of the Sentinel-1 Mission Performance Cluster (SAR-MPC) project funded by ESA.
This implementation is merging preliminary implementation performed separately by CLS and IFREMER.

Those features are used as input of the ML models made available by SAR-MPC in the AUX_ML2 auxiliary files published in https://sar-mpc.eu
