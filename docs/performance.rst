Performance
===========

Compute time vs. number of kernels
----------------------------------

The CWAVE parameters :math:`C_{n,m}` are indexed by the Gegenbauer index
:math:`n` (``cwave_Nk``) and the harmonic index :math:`m` (``cwave_Nphi``). The
cost is dominated by (i) building the kernel basis,
:math:`\mathcal{O}(N_k \cdot N_\varphi)`, and (ii) the projection integral,
:math:`\mathcal{O}(N_k \cdot N_\varphi \cdot n_{\text{grid}}^2)`. Increasing
:math:`N_k` or :math:`N_\varphi` adds kernels, so the time grows
approximately linearly in :math:`N_k \cdot N_\varphi`.

:func:`cwaves.compute_cwave_parameters` on one realistic one-sided
cross-spectrum — a real ESA OCN WV tile resampled onto a **128 x 128** regular
grid (wavelength range 25-600 m). Measured on a laptop (Python 3.12); treat the
values as an order of magnitude, not a guarantee.

The default (:math:`N_k=4`, :math:`N_\varphi=5`) completes in about **12 ms**
per cross-spectrum. A full IW subswath (hundreds of tiles) is therefore
comfortably fast even at :math:`N_k=4`, :math:`N_\varphi=5`.

Regenerating the table
----------------------

The numbers above are produced by :file:`docs/generate_benchmark.py` :

.. code-block:: bash

   python docs/generate_benchmark.py

The script times ``compute_cwave_parameters`` on the same 128 x 128 tile for a
grid of ``cwave_Nk`` / ``cwave_Nphi`` values and prints a Markdown table. The
figures in the documentation are likewise regenerated by
:file:`docs/generate_figures.py`.
