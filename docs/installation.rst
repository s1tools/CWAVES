Installation
============

Stable release
--------------

``cwaves`` is available on PyPI :

.. code-block:: bash

   pip install cwaves

From source
-----------

Clone the repository and install in development mode (includes the test and lint
dependencies) :

.. code-block:: bash

   git clone https://github.com/s1tools/CWAVES
   cd CWAVES
   pip install -e ".[dev]"
